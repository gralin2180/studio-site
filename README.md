# Studio Site

Fixed-price websites and custom apps for whoever needs them. Marketing site (Vite + React).

## Dev

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub → import on [Vercel](https://vercel.com). Framework: Vite. Output: `dist`.

No Supabase / env vars required for this site.

## Brand

Source of truth: `src/brand.ts` (`Pinekraft Studio`, `pinekraftstudio.com`, packages, portfolio links).
